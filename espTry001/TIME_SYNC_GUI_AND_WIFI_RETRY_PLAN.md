# 2.8 英寸设备时间同步 GUI 与 Wi-Fi 重连改进规划

## 1. 目标

在不破坏现有 `ESPTIME1` 串口协议和 RTC 功能的前提下，完成以下改进：

1. 增加 C# WinForms 图形化时间同步工具，替代日常使用中的 Python 命令行。
2. 在下位机 `TIME SYNC` 页面明文显示已保存的 Wi-Fi 名称和密码，方便用户按页面内容设置手机热点。
3. 设备开机未连接 Wi-Fi 时继续进行非阻塞重试；进入时间同步页面时立即重试，并支持手动重试。
4. NTP 不再只依赖腾讯服务器，改成面向国内外网络的多服务器回退。
5. 保留无网络时由电脑直接写入 RTC 的能力。
6. 将新工具加入现有一键打包脚本和 2.8 英寸使用说明。

## 2. 使用流程

### 2.1 仅同步电脑时间

1. 下位机进入 `SYSTEM INFO -> TOOLS MENU -> TIME SYNC`。
2. 打开 `TimeSyncManager.exe`。
3. 选择设备串口并点击“连接设备”。
4. 点击“同步电脑时间到 RTC”。
5. 工具读取同步后的 RTC 状态并显示结果。

该流程不依赖 Wi-Fi。

### 2.2 配置手机热点并进行 NTP 校时

1. 在 C# 工具中输入热点名称和密码并保存到设备。
2. 下位机页面明文显示已保存的名称和密码。
3. 用户将手机热点设置为页面所示内容。
4. 设备立即尝试连接，并在失败后按退避间隔继续重试。
5. 联网后使用多个 NTP 服务器自动完成校时。

## 3. C# 工具设计

新增 `tools/TimeSyncManager.cs`，生成 `TimeSyncManager.exe`。界面保持单窗口、少按钮：

- 串口选择和刷新；
- 连接设备；
- 当前电脑时间、设备 RTC 时间及来源；
- 同步电脑时间到 RTC；
- Wi-Fi 名称、密码；
- 显示/隐藏密码；
- 保存 Wi-Fi 并立即尝试 NTP；
- 立即重试 NTP；
- 清除 Wi-Fi 配置；
- 当前 Wi-Fi/NTP 状态和操作日志。
- 简体中文与 English 即时切换，并记住上次选择。

工具继续使用现有 `ESPTIME1` 单行文本协议，避免引入额外运行时和 Python 依赖。

## 4. ESPTIME1 协议扩展

保留现有命令：

```text
PING
GET
SET <unix_utc>
WIFI STATUS
WIFI SET <ssid_hex> <password_hex_or_dash>
WIFI CLEAR
NTP START
CLOSE
```

新增兼容命令：

```text
WIFI GET
```

响应返回十六进制编码的完整 SSID 和密码，避免空格、中文及控制字符破坏单行协议。该命令只在设备主动进入 `TIME SYNC` 独占页面后可用。

## 5. 下位机页面改进

`TIME SYNC` 页面显示：

- RTC 当前时间和来源；
- 完整 Wi-Fi 名称；
- 完整 Wi-Fi 密码；
- Wi-Fi/NTP 当前状态；
- 自动重试倒计时或连接进度；
- `RETRY` 触摸按钮；
- 电脑端工具提示。

页面空间不足时对长名称和密码按屏幕宽度截断，但 C# 工具仍可读取完整内容。

## 6. Wi-Fi 自动重连策略

Wi-Fi 和 NTP 全程使用非阻塞状态机：

1. 开机存在凭据时立即尝试一次。
2. 连接或 NTP 超时后进入等待重试状态。
3. 使用 5、10、30、60 秒退避间隔，之后每 60 秒重试。
4. 进入 `TIME SYNC` 页面时立即触发一次重试。
5. 点击 `RETRY` 时立即触发一次重试。
6. Wi-Fi 连接后若 NTP 失败，关闭当前网络会话并等待下一次重试。
7. 成功写入 RTC 后停止高频重试，按较长周期进行后续网络校时。
8. 所有状态切换不得阻塞触摸、USB、RS485 或日志任务。

## 7. NTP 服务器策略

不再把腾讯 NTP 作为唯一来源。使用多服务器配置，例如：

```text
pool.ntp.org
time.cloudflare.com
time.google.com
ntp.tencent.com
```

ESP32/SNTP 按可用性选择服务器。在美国等海外网络中优先使用全球服务，腾讯作为国内网络的补充。

RTC 仍保存 UTC，当前屏幕和 CSV 保持项目既有的 UTC+08:00 显示规则。本次不引入可变时区，避免同时改变历史日志语义；如后续需要显示美国当地时间，再单独规划时区配置。

## 8. 安全与边界

- 用户明确要求下位机页面明文显示 Wi-Fi 密码；说明书中应提醒该页面仅适合受控现场使用。
- Wi-Fi 凭据仍保存在设备 NVS，不写入日志和传感器配置文件。
- `WIFI GET` 只在用户手动进入时间同步独占页面时响应。
- C# 工具提供密码显示/隐藏选项，默认隐藏电脑输入框内容。
- 串口协议继续限制 SSID 和密码的 UTF-8 字节长度。

8. 增加协议/逻辑测试，运行固件编译和打包验证。

## 10. 验收标准

- C# 工具无需 Python 即可完成 RTC 同步、Wi-Fi 配置、状态查询和 NTP 重试。
- 无 Wi-Fi 开机后再开启同名手机热点，设备可在不重启的情况下自动连接并校时。
- 进入时间同步页面或点击 `RETRY` 会立即开始新尝试。
- 页面能够明文显示保存的 Wi-Fi 名称和密码。
- 海外网络不依赖腾讯 NTP，任一可用全球 NTP 服务器即可完成同步。
- 无网络时电脑直写 RTC 仍可成功。
- 新 EXE 和说明文档进入一键发布包。
- 现有 Sensor Profile、Calibration Profile、日志导出和 PASS/MASTER 功能不受影响。
